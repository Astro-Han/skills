# Explain Visually

Explain the topic to someone who knows nothing about it, using big visuals and few words. Keep the central truth; drop detail before accuracy.

Use the closest available visual artifact tool—image, diagram, widget, or equivalent—and follow its own guidance. Use HTML only when no suitable visual tool is available.

Done means the visual itself makes the central idea understandable without the original technical material.
